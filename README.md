# AlphaEdge Trading Bot

## Overview

AlphaEdge is an autonomous trading bot that scans for trading signals on a set of symbols (metals, crypto, etc.) and places trades on the **Exness (MT5 Trial)** broker. The bot runs a 2‑minute scan cycle via `run_autonomous_scanner.py` and can also be controlled manually through a Telegram bot.

## Features

- **Automated scanning** every 2 minutes (AlphaEdge strategy). 
- **Telegram integration** with commands:
  - `/status` – health check.
  - `/scan` – trigger a manual scan.
  - `/trade <symbol> <volume> <BUY|SELL>` – place a manual trade.
  - `/positions` – list open positions.
  - `/pnl` – show today’s P&L.
- **Broker selection** – Deriv is disabled; the bot uses Exness credentials defined in `trade_config.py`.
- **Risk limits and lot‑size scaling** are configured in `trade_config.py`.

## Setup

1. **Clone the repository** (already done in this workspace).
2. **Install dependencies** (run in the workspace root):
   ```
   pip install -r requirements.txt            # includes MetaTrader5, python‑telegram‑bot, pandas, numpy
   ```
3. **Configure credentials** in `trade_config.py`:
   - `TELEGRAM_TOKEN` – token from BotFather.
   - `TELEGRAM_CHAT_ID` – your Telegram chat ID (restricts bot usage).
   - `EXNESS_CONFIG` – login, password, server for the Exness MT5 trial.
   - Ensure `USE_DERIV = False`.
4. **Run the autonomous scanner**:
   ```
   python run_autonomous_scanner.py
   ```
   This will start a loop that runs the AlphaEdge scan every 2 minutes and logs output to `autonomous_trading.log`.
5. **Start the Telegram bot** (optional, for manual control):
   ```
   python telegram_bot.py
   ```
   The bot will respond only to the chat ID configured above.

## Connecting MetaTrader 5 via MCP

The bot uses the **MetaTrader5** Python package, which communicates with the local MT5 terminal through the MetaTrader **MCP (MetaTrader Connector Protocol)**. To ensure the connection works:

1. **Install the MT5 client** on the machine (the Exness trial provides the terminal).
2. **Add the MT5 terminal path** (if not in the default location) in `trade_config.py` via `MT5_PATH`.
3. The bot calls `mt5.initialize(login=..., password=..., server=..., path=MT5_PATH)` – this opens a session with the broker. No extra MCP server configuration is required; the Python package handles it internally.
4. Verify the connection:
   ```python
   import MetaTrader5 as mt5
   mt5.initialize(login=..., password=..., server=..., path=MT5_PATH)
   print(mt5.version())
   mt5.shutdown()
   ```
   You should see the MT5 library version without errors.

## Debugging & Common Issues

- **Import errors** – Ensure the hidden `.agents/trading_bot_skills` directory is on `sys.path`. The `telegram_bot.py` script adds it automatically.
- **MT5 not initializing** – Check that the credentials are correct and that the MT5 terminal can run in demo mode.
- **Telegram bot not responding** – Verify the token and chat ID, and that the bot is not blocked by Telegram.
- **Permission errors** – Run the scripts with a user that has access to the MT5 installation folder.
